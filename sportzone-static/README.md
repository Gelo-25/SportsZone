# SportZone Static Storefront

A static HTML/CSS/JavaScript sports shop demo for the Philippine market.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet is required for the remote Unsplash product images and Google Fonts. The store logic itself uses local HTML/CSS/JS.

## Files
- `index.html` — page structure
- `styles.css` — responsive theme and layout
- `script.js` — sample products, search/filter/sort, cart, demo checkout

## Demo limitations
- Product data and prices are illustrative.
- Cart is saved in this browser using localStorage.
- Checkout is a demo only. It does not transmit or persist orders on a server.
- No real payments, stock checks, shipping quotes, courier tracking, supplier integration, or email notifications.
- Contact link is a placeholder (`hello@example.com`).
- External images/fonts need an internet connection.

## Customize
Edit the `PRODUCTS` and `CATEGORIES` arrays in `script.js` to change products, prices, categories, and images.
